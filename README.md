# Прогнозирование продаж: анализ и предобработка временного ряда

Домашнее задание по курсу «Прогнозирование временных рядов и обработка сигналов». На транзакциях датасета [Online Retail (UCI)](https://archive.ics.uci.edu/dataset/352/online+retail) строится временной ряд продаж одного товара и исследуется перед прогнозированием: качество данных, выбросы, тренд, сезонность и стационарность.

**Товар:** `85099B` JUMBO BAG RED RETROSPOT. Товар `85123A`, разобранный на занятии, не используется.
**Показатель:** число проданных штук (`Quantity`) по фактическим продажам, то есть без отменённых счетов, возвратов и строк с нулевой ценой.

## Структура

| файл | содержимое |

| `sales_ts_analysis.ipynb` | весь анализ по шагам 1–7: код, графики, интерпретация |

## Запуск

```bash
pip install -r requirements.txt
jupyter execute sales_ts_analysis.ipynb   # или открыть в Jupyter и выполнить все ячейки
```

При первом запуске `ta.download_dataset("data/raw")` скачивает `Online Retail.xlsx` (~23 МБ) с UCI. Если сервер отдаёт файл медленно, его можно скачать вручную по ссылке выше и положить в `data/raw/`. Чтение Excel занимает около 10 с, после этого данные кэшируются в pickle. Ноутбук целиком выполняется примерно за 15 с.

## Что сделано

1. **Ряд.** Очистка удалила 2,2 % строк. Ряд построен по дням, неделям (Вс–Сб) и месяцам. По календарю магазина видно, что он закрыт по субботам и в праздники Великобритании, а торговая неделя длится с воскресенья по пятницу. Для сравнения периодов разной длины считаются продажи на торговый день.
2. **Качество данных.**
   - Все 69 пропусков дневного ряда — нерабочие дни, они оставлены как NaN.
   - Торговые дни без продаж (5 дней) — реальные нули.
   - Для STL и разностей используется регулярная сетка «Вс–Пт» с 04.01 по 08.12.2011. На ней пришлось заполнить 7 праздничных дней (2,4 %), их заполняют средним того же дня недели соседних недель.
   - Выбросы искались тремя методами: IQR, фильтр Хампеля и фильтр Хампеля на лог-шкале.
3. **Описательный анализ.**
   - Распределение дневных продаж скошено вправо.
   - По классификации Syntetos–Boylan спрос «неустойчивый» (ADI 1,02, CV² 1,38).
   - Уровень меняется во времени (тест Манна–Уитни по половинам ряда).
   - Шум мультипликативный (λ Бокса–Кокса ≈ 0,2).
   - Отдельно разобраны профиль по дням недели, ACF/PACF и структура заказов.
4. **Декомпозиция.** Робастная STL на log(1 + x) с периодом 6 торговых дней. Значимость силы сезонности проверена перестановочным тестом. Для недельного ряда тренд выделен через LOWESS.
5. **Стационарность.**
   - Тесты ADF и KPSS проведены в вариантах со средним и с трендом.
   - Проверены три преобразования: первая разность, сезонная разность и удаление тренда.
   - Устойчивость выводов к выбросам проверена отдельно.

## Основные результаты

- **Выбросы.** Крупные пики (до 1 583 шт. в день) — настоящие оптовые заказы по 200–1 200 шт. На 2,7 % строк от 20 клиентов приходится треть объёма. Они не удалялись: это реальный спрос. Их влияние снижено логарифмированием, а выводы проверены на рядах с заменёнными пиками и без крупных строк.
- **Тренд.** Уровень за год вырос примерно вдвое: 108 → 227 шт. на торговый день, по месяцам. Рост неравномерный, с подъёмами весной, в августе и в октябре–ноябре.
- **Сезонность.** Недельная сезонность подтверждена: критерий Краскела–Уоллиса (p ≈ 5·10⁻⁹), пики ACF на лагах 6, 12 и 24, перестановочный тест силы сезонности STL (F = 0,20, p ≈ 0,003). Главная особенность — провал в воскресенье, к концу года он углубился. Годовую сезонность по одному году данных установить нельзя.
- **Стационарность.** Исходный ряд нестационарен по среднему: KPSS отвергает стационарность. Единичного корня нет, ADF отвергает его во всех вариантах. Ряд тренд-стационарен. Первая разность делает его стационарным, но приводит к передифференцированию (ACF(1) = −0,41), сезонная разность — тоже (ACF(6) = −0,51).
- **Выбранное преобразование:** log(1 + x) с удалением тренда и учётом дня недели. Линейный тренд — только приближение: если заменить пики медианой, KPSS отвергает стационарность вокруг прямой. Поэтому для прогноза лучше гибкий тренд.
